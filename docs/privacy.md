# 隐私与授权

## 这不是“复活”

- Hindsight 存的是你整理/授权的事实条目，不是她本人。
- Edge TTS 是通用音色，不是她的声音；本项目不做声音克隆。
- 角色输出是统计性模仿，可能出错、过时或与真人矛盾。
- 不要对第三方声称“这是她”“她回来了”“她同意你这样用”。

## 使用前确认

使用他人的聊天记录、照片、声音、姓名、关系细节，可能涉及隐私权、个人信息权益和人格权益。请确认：

- 你有合法依据处理这些聊天记录；
- 对方或相关权利人已知情/同意，或法律允许；
- 不用于骚扰、跟踪、冒充、诈骗、敲诈、贬低或操控；
- 不向未成年人提供不适龄内容；
- 遵守你所在地区法律和平台条款。

如果你不确定，先不要导入真实聊天记录；用虚构样例测试。

## 数据流向

| 数据 | 去哪里 | 是否留存 |
|---|---|---|
| 麦克风音频 | 浏览器 → DSH 主机 → SiliconFlow ASR | 不落盘；请求结束即释放 |
| 转写文字 | DSH 会话历史 | 留存，直到你删除会话 |
| AI 回复 | DSH 会话历史 | 留存 |
| TTS 文本 | DSH 主机 → 微软 Edge TTS | 不写入 DSH；MP3 缓存在本机 |
| 记忆事实 | DSH 主机 → 本地 Hindsight / Docker volume | 留存，直到删除 |
| API Key | `secrets.json` / 环境变量 | 本机明文，当前用户可读 |

## 不要写入记忆的内容

- 密码、验证码、私钥、API Key；
- 身份证、护照、银行卡、社保号；
- 精确住址、门牌号、实时位置；
- 医疗诊断、性取向、政治倾向等高度敏感信息（除非你明确需要且理解风险）；
- 第三人的隐私；
- 未经同意的私密照片/音频描述。

## 删除

- 删除单条记忆：Hindsight 的 document/memory API；
- 删除整个记忆库：

  ```powershell
  docker compose down -v
  ```

- 删除 DSH 会话：在 DSH 会话列表删除；
- 删除本地设置/密钥：

  ```powershell
  Remove-Item "$env:USERPROFILE\.dsh\xiaoyuer" -Recurse -Force
  ```

- 删除 TTS 缓存：上面的 `tts-cache` 目录。

删除 Docker volume 不可恢复。删除前先备份（如果还需要）。

## 安全建议

- Tailscale 只在 tailnet 内使用，不开 Funnel；
- 不要把带 token 的 URL 发出去；
- 不要把 `secrets.json`、`.env`、聊天记录提交 Git；
- 定期更新 DSH、Hindsight、edge-tts；
- 共享电脑上退出登录 / 清除 cookie；
- 备份记忆库时加密。

## 危机场景

如果用户表达自伤、他伤或严重危机：

- 不要用角色扮演淡化；
- 先回应情绪，再明确建议联系身边可信的人、当地紧急服务或专业机构；
- 不要承诺“我永远在”“只有我懂你”；
- 不要鼓励断绝现实关系。

人设卡已经写入这些边界；修改人设时请保留。
